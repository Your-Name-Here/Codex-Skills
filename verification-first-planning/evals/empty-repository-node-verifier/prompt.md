# Eval prompt

Plan a URL-shortening HTTP service in this initially empty repository. Node.js is available, but there is no application scaffold, package manifest, or test framework. The observable behavior is:

- submitting a destination URL returns a short URL;
- visiting the short URL redirects to the stored destination;
- repeated submission of the same destination returns the existing short code;
- stored mappings survive an application restart.

Create a planning handoff with a specification, verification matrix, baseline results, and implementation task list. Create and run executable verification where practical. Do not implement the URL-shortening product or prescribe internal architecture.
