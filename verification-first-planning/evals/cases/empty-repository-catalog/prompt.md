# Eval prompt

Plan a small searchable catalog in this initially empty repository. Node.js is available, but there is no application scaffold, package manifest, or test framework. The observable behavior is:

- a user can add a catalog entry with a name and description;
- a user can search entries by words in either field;
- search results include matching entries and omit non-matching entries;
- an empty search returns a useful validation message.

Create a planning handoff with a specification, verification matrix, baseline results, and implementation task list. Create and run executable verification where practical. Do not implement catalog behavior or prescribe internal architecture.
