# Components

- App shell: framed work area, side palettes, visible separators.
- Buttons: raised by default, inset when active, never glassy.
- Panels: use boxed sections with labeled headers and clear edges.
- Lists and grids: align to fixed columns or visible rhythm lines.
- Status indicators: badges and lights should look intentional, not generic.
- Empty states: use concise copy and a small illustrative block, not giant lifestyle art.
