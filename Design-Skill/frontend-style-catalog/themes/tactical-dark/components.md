# Components

- App shell: top toolbar plus left nav or inspector rail. Keep primary actions visible.
- Tables: compact rows, sticky headers, monospace for IDs and numeric data.
- Panels: group controls by task, not by arbitrary symmetry.
- Filters: inline chips, segmented toggles, and narrow inputs beat giant form blocks.
- Status badges: use color plus label. Never rely on color alone.
- Dialogs: keep them narrow and task-specific. Long workflows should stay inline.
